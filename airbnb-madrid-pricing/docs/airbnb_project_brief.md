# Airbnb Madrid Pricing Project Brief

## Business case

A property-market client owns a substantial number of Airbnb listings in Madrid and asks for advice on optimizing their prices using data.

## Project objective

Build a data story that provides context for the problem, defines the analytical question and scope, sets out the analysis roadmap, and presents the main insights.

The supplied project data are split across five files in the `Ficheros` folder: host, location, property, rental conditions, and review information. The source brief does not specify a public dataset citation.
